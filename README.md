## Executing a Project
Each project contains a "run" script which builds and runs the respective project.
#### Steps
<ol>
    <li>Ensure you open a terminal session in the respective project's directory.</li>
    <li>Simply run the command "./run.bat" on Windows or "./run.sh" on MacOS and Linux.</li>
</ol>
